# MY APPS HUB V.1 — PWA

## Kandungan
- `index.html` — struktur portal
- `style.css` — reka bentuk responsif
- `script.js` — katalog, carian, penapis dan pautan e-mel
- `manifest.webmanifest` — tetapan PWA
- `sw.js` — cache fail portal untuk penggunaan luar talian
- `icon.svg` — ikon aplikasi

## Terbitkan melalui GitHub Pages
1. Cipta atau buka repositori GitHub untuk portal ini.
2. Muat naik semua fail dalam folder ini ke akar repositori (bukan fail ZIP sahaja).
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, pilih branch `main` dan folder `/(root)`, kemudian **Save**.
5. Tunggu GitHub Pages menerbitkan laman dan buka URL yang dipaparkan.
6. Buka URL menggunakan HTTPS. Pada pelayar yang menyokong pemasangan PWA, pilih **Install app / Pasang aplikasi**.

## Nota penting
- PWA ini cache fail portal asas. Ia tidak memuat turun atau menjadikan aplikasi luaran berfungsi sepenuhnya tanpa internet.
- Pautan katalog adalah berdasarkan URL yang diberikan. URL aplikasi perniagaan/kariah yang belum diberikan tidak direka-reka.
- Butang permohonan membuka aplikasi e-mel pengguna dengan draf yang telah diisi; pengguna masih perlu menekan **Send/Hantar**.
- Fungsi AI atau kandungan yang bergantung pada pelayan pihak ketiga memerlukan sambungan internet.
- Semak setiap pautan dan kandungan sebelum berkongsi portal secara umum.
